## Project: Personal Loan Campaign  
### Course: Machine Learning

### Project Overview
This project focuses on identifying bank customers who have a **high likelihood of purchasing a personal loan**. By analyzing customer data, the objective is to understand the key attributes that influence loan acquisition.

Using these insights, a predictive machine learning model is developed to capture patterns in customer behavior and financial characteristics. The model helps the bank **identify potential loan buyers**, enabling more targeted marketing campaigns and improving overall conversion rates.

The project demonstrates how data-driven insights can support strategic marketing decisions and improve customer targeting in the banking sector.

---

### Skills & Tools Covered

- **Exploratory Data Analysis (EDA)**
- **Data Preprocessing**
- **Decision Tree Model Building**
- **Model Performance Evaluation and Optimization**
- **Business Insights and Recommendations**

---

### Project Objective
The goal of this project is to build a machine learning model that can:

- Predict customers who are likely to purchase a personal loan  
- Identify key factors influencing loan acceptance  
- Support targeted marketing strategies  
- Improve conversion rates and marketing efficiency
